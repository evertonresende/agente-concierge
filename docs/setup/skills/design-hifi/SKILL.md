# Hi-Fi Mockup

Crie mockups de alta fidelidade com as seguintes especificações:

## Formato
- Design canvas com pan/zoom (mouse wheel + drag)
- Variações lado-a-lado com label descritivo ("Opção A: minimalista", "Opção B: expressiva")
- Mínimo 2, ideal 3 variações por componente/tela
- Escala 1:1 com device frame se for mobile/tablet

## Qualidade visual
- Tipografia refinada: tamanhos, pesos e line-heights corretos
- Espaçamento consistente baseado em escala (4px, 8px, 16px, 24px, 32px...)
- Sombras com propósito: elevação, não decoração
- Cores com contraste WCAG AA mínimo

## Conteúdo
- Copy real ou próximo do real — sem lorem ipsum
- Dados representativos (nomes, valores, datas reais)
- Estados: default, hover, active, disabled, erro

## Antes de produzir
1. Perguntar: componente isolado ou tela completa? qual plataforma?
2. Confirmar tokens/design system existente
3. Propor direções visuais antes de implementar (minimalista vs expressivo vs funcional)
